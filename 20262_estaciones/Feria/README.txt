FERIA WEB — ESTACIONES PARA UNA ALCALDIA
========================================

Esta carpeta contiene una demostración web moderna que usa los algoritmos
reales de Curso/estaciones. No requiere instalar Flask, Node ni paquetes.

Ejecución:

  cd 20262_estaciones/Feria
  python app.py

Después abrí en el navegador:

  http://127.0.0.1:8000

La aplicación permite escoger pequeña, comuna o ciudad, visualizar el mapa de
la red, incidentes cubiertos, lotes seleccionados, métricas y tabla de la
propuesta. La opción exacta se restringe para ciudad porque no es viable.
